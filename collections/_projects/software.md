For the first series of [Material Programming Workshops]({{ '/projects/workshops' | prepend: site.baseurl }}), we made a [forked version](https://agnescameron.github.io/knitout-live-visualizer/) of the CMU Knitout Visualiser tool to provide a visualisation interface that would allow students to write knitting code using the knitout-frontend tools, add common features like a waste section, and export directly to the kcode format. Additionally, we modified the tool to run asynchronous JS, so you can do fun things like pull data directly into the editor.

We've also worked with Chee and Mimi from research software lab Ink&Switch to translate this tool into their collaborative software platform Patchwork. As Patchwork is still in beta, this is not currently in general use, but if you are a Kniterate user and are interested in accessing this, please get in touch with us.

For more information on how to write code that makes knit, please see the [guide](https://soup.agnescameron.info/2026/04/09/cheatsheet.html) here, and for more information about the design process, there is a write-up [here](https://soup.agnescameron.info/2026/04/01/transfers.html).
